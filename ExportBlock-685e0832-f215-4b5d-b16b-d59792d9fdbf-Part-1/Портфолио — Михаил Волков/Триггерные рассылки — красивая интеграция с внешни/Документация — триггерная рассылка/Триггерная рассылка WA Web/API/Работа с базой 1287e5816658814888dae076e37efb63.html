Метод 1. Получение списка колонок.

Данные которые получит пользователь:

  1. Id колонки
  1. Имя колонки
  1. Тип данных
Ошибки при получении списка колонок
Код ошибкиОписание
DATA_ERRORНеверный формат запроса

SERVER_ERRORОшибка сервера
